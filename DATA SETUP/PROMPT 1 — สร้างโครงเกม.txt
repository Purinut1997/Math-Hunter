==============================
CORE GAME RULE
==============================

เกมนี้ไม่ใช่ RPG

ห้ามมี:
- XP
- Level
- Coin
- Skill Tree
- Equipment
- Inventory
- Attack Stat
- Defense Stat

ผู้เล่นมีเพียง:

Player HP = 5
Correct Streak
Current Stage

กฎการต่อสู้:

ตอบถูก
→ Monster HP -1
→ Correct Streak +1

ตอบผิด
→ Player HP -1
→ Correct Streak = 0

ตอบถูกติดต่อกัน 3 ครั้ง
→ Player HP +1
→ HP ห้ามเกิน 5
→ Correct Streak = 0

ถ้า Player HP = 0
→ Game Over
→ Restart ด่านปัจจุบันตั้งแต่ต้น

เมื่อผ่านด่าน
→ Player HP กลับเป็น 5 เต็ม
→ ปลดล็อกด่านถัดไป

==============================
QUESTION SYSTEM
==============================

ห้ามใช้ชุดโจทย์แบบ Fixed Question Bank

ต้องสร้าง Question Generator
ที่สุ่มสร้างโจทย์ใหม่ทุกครั้ง

ทุกโจทย์มี:
- questionId
- topic
- difficulty
- questionText
- correctAnswer
- distractors 3 ตัว
- answerChoices 4 ตัว

ต้องสุ่มตำแหน่งคำตอบถูกทุกครั้ง

เก็บโจทย์ล่าสุด 15 ข้อ
และห้ามสร้างโจทย์ซ้ำในช่วงดังกล่าว

สร้าง validateQuestion()
เพื่อตรวจสอบว่า:

- คำตอบถูกต้องจริง
- ตัวเลือกไม่ซ้ำ
- มีคำตอบถูกเพียง 1 ตัว
- ไม่มี NaN
- ไม่มีหารด้วย 0
- เนื้อหาไม่เกินระดับชั้น
- Difficulty ถูกต้อง
