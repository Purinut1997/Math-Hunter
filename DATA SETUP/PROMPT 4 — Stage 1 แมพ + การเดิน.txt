==================================================
PLAYER MOVEMENT
==================================================

เกมเป็น 2D Top-Down

Player เดินได้ 4 ทิศทาง:

UP
DOWN
LEFT
RIGHT

Desktop:

WASD
Arrow Keys

Mobile Landscape:

Virtual Analog Joystick

Joystick เป็น Analog Input
แต่ Logical Movement ต้องแปลงเป็น
4 Cardinal Directions

ห้ามเดินทแยงเชิง Logic

ถ้า Input มีทั้ง X และ Y:

ใช้ Axis ที่มีค่ามากกว่า

เช่น:

abs(x) > abs(y)
→ LEFT / RIGHT

abs(y) > abs(x)
→ UP / DOWN

==================================================
ENCOUNTER RULE
==================================================

เมื่อ Player เข้า Trigger ของ Active Encounter:

1. หยุด Player
2. Lock Movement
3. เริ่ม Encounter
4. Monster Combat System จะจัดการต่อภายหลัง

เมื่อ Encounter Completed:

1. mark completed = true
2. unlock related gate
3. activate next encounter
4. return player control

Encounter ที่ Completed แล้ว
ห้าม Trigger ซ้ำใน Run เดียวกัน
