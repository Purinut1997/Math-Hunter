NORMAL MONSTER TIMER

Normal Monster:

==================================================
ENCOUNTER START
==================================================

เมื่อ Player เข้า Active Encounter Trigger:

1. Lock Player Movement

2. Face Player toward Monster

3. Monster เล่น Idle Animation

4. แสดง Combat UI

5. Generate Question ใหม่

6. แสดง Answer Choices 4 ตัว

==================================================
CORRECT ANSWER FLOW
==================================================

เมื่อ Player ตอบถูก:

1. Disable Answer Input ชั่วคราว

2. Player เล่น Attack Animation

3. Monster เล่น Hit Animation

4. Monster HP -1

5. Correct Streak +1

6. Update UI

ถ้า:

Correct Streak >= 3

ให้:

Player HP +1

แต่:

Player HP <= Player Max HP

แล้ว:

Correct Streak = 0

แสดง Effect:

HEAL +1

ถ้า HP เต็ม:

แสดง:

MAX HP

แต่ยัง Reset Streak = 0

==================================================
MONSTER SURVIVES
==================================================

ถ้า:

Monster HP > 0

หลัง Hit Animation:

Generate Question ใหม่ทันที

Question ใหม่ต้อง:

- ไม่ใช่ข้อเดิม
- สุ่ม Answer Position ใหม่
- Validate ก่อนแสดง

แล้ว Enable Answer Input

==================================================
MONSTER DEFEATED
==================================================

ถ้า:

Monster HP <= 0

ให้:

1. เล่น Monster Death Animation

2. Disable Monster Collision

3. Hide Combat UI

4. Encounter.completed = true

5. Unlock Progress Gate

6. Activate Next Encounter

7. Return Player Movement

8. Monster ห้ามเกิดซ้ำใน Run ปัจจุบัน

==================================================
WRONG ANSWER FLOW
==================================================

เมื่อ Player ตอบผิด:

1. Disable Answer Input

2. Correct Streak = 0

3. Monster เล่น Attack Animation

4. Player เล่น Hit Animation
   ถ้ามี Asset
   ถ้ายังไม่มีให้ใช้ Damage Flash ชั่วคราว
   แต่ห้ามเปลี่ยนตัว Player เป็น Placeholder

5. Player HP -1

6. Update HP UI

7. แสดงคำตอบที่ถูกต้อง
ประมาณ 1–1.5 วินาที

8. Generate Question ใหม่

ห้ามให้ Player ตอบโจทย์เดิมซ้ำทันที

==================================================
MONSTER POSITION
==================================================

Monster ต้องอยู่บริเวณ
Encounter Trigger ที่กำหนดใน Stage 1

อย่าสุ่ม Spawn ทั่ว Map

แต่สามารถปรับตำแหน่งภายใน Encounter Area
เล็กน้อยเพื่อให้ดูเป็นธรรมชาติ

==================================================
MONSTER IDLE STATE
==================================================

Monster ที่ยังไม่ Active:

สามารถแสดงอยู่ใน Map ได้

แต่:

ไม่เริ่ม Combat
จน Encounter ก่อนหน้าสำเร็จ

หรือเลือกซ่อน Monster ไว้จน Active
ก็ได้ถ้าเหมาะกับ Flow

Prefer:

ให้เห็น Monster ล่วงหน้า
เพื่อให้ผู้เล่นรู้ว่ากำลังเดินไปหาอะไร
